Something I built

My AWS re/Start final project, still used by students.

AWS Services Glossary

A serverless web app where bootcamp students add, edit, search and filter descriptions of AWS services.

  • Static frontend on S3 and CloudFront, REST API on API Gateway with four Python Lambda functions.
  • DynamoDB with a condition expression, so the database itself rejects duplicates.
  • The whole stack in AWS SAM: one command to redeploy anywhere.
  • Runs within the AWS Free Tier, with the version 1 trade-offs written up.
